# Configuration

Generated by `pnpm config:docs` from `apps/lyra/src/main/envSpec.ts` and
`apps/lyra/src/main/tasks/args.ts`. Do not edit by hand; CI fails when it is out of date.

Lyra is configured in its Settings window. The environment variables below are for setups the
window doesn't cover: a shared models folder, a mirror, keys from a secrets manager, a proxy.
They are read once at startup. A value that is set but malformed stops Lyra with a message naming
the variable; an empty value is the same as unset. Names follow the tool that defined them
(the AI SDK providers, Hugging Face) where there is one, so a machine already set up for those works
as is; only Lyra's own settings take the `LYRA_` prefix.

Lyra reads the process environment, not a `.env` file.

| Variable | Kind | What it does | When unset |
| --- | --- | --- | --- |
| `LYRA_NOTES_DIR` | path | Notes folder a new profile starts with. Once settings are saved, the saved folder is used. | `~/.lyra` |
| `LYRA_MODELS_DIR` | path | Where downloaded models are kept. Point smoke tests and evals at one folder to download each model once. | `<userData>/models` |
| `HF_ENDPOINT` | url | Hugging Face mirror to download models from (the same variable the Hugging Face tools read). Files are still checked against their pinned sha256. | `https://huggingface.co` |
| `ANTHROPIC_API_KEY` | secret | Anthropic API key. Used when no key is saved in Settings; a saved key wins. Having a key never sends anything: summaries use a cloud model only when the user picks one. | the key saved in Settings, if any |
| `ANTHROPIC_BASE_URL` | url | Anthropic API endpoint, for a proxy or gateway. Include the version path, as the AI SDK expects (`https://gateway.example/v1`). | `https://api.anthropic.com/v1` |
| `OPENAI_API_KEY` | secret | OpenAI API key. Used when no key is saved in Settings; a saved key wins. Having a key never sends anything: summaries use a cloud model only when the user picks one. | the key saved in Settings, if any |
| `OPENAI_BASE_URL` | url | OpenAI API endpoint, for a proxy or gateway. | `https://api.openai.com/v1` |
| `GOOGLE_GENERATIVE_AI_API_KEY` | secret | Google Gemini API key. Used when no key is saved in Settings; a saved key wins. Having a key never sends anything: summaries use a cloud model only when the user picks one. | the key saved in Settings, if any |
| `ELECTRON_RENDERER_URL` | url | Set by `electron-vite dev` to the dev server. Read only in development builds. | the bundled renderer |

Paths must be absolute. URLs must be `http` or `https`. Secrets are never written to the log;
the startup line lists which variables are set, not their values.

## One-off tasks

Smoke tests, screenshots and meeting replays run through the same binary as the app, chosen on
the command line. Each runs in a throwaway profile and exits with its result. In development the
`pnpm` scripts launch them (`smoke:ui`, `screenshot`, `smoke:meeting`, `eval:*`,
`replay:session`).

```text
lyra smoke                                  UI and IPC smoke test (pnpm smoke:ui)
lyra screenshot [--review <dir>]            README shot; --review captures every state
lyra meeting <mic.wav> [system.wav]         the real speaker pipeline (pnpm smoke:meeting)
  [--offline] [--no-relabel] [--output <file.json>] [--notes local|cloud] [--enroll <owner.wav>]
```
