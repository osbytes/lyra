Send a session, a transcript line or selected text to Claude, Claude Code, ChatGPT, Cursor, Zed, GitHub Copilot or T3 Code with "Send to…" in the right-click and session menus. Only the apps you have installed are listed, with their own icons, and each opens with the text ready in its prompt box for you to send. For a session, tick what to include (the transcript, the summary, sections, decisions, action items, open questions, your notes); Lyra remembers the choice. Every right-click menu item now has an icon.
