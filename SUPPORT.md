# Support

## Getting help

- **Bugs and feature requests:** [open an issue](https://github.com/osbytes/lyra/issues/new/choose).
  For a bug, attach the relevant lines of the log (see
  [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md#logs)); it holds ids and timings, not what
  your notes say.
- **Security problems:** report privately, as [SECURITY.md](SECURITY.md) describes. Never in a
  public issue.

## Supported versions

Lyra is maintained by volunteers. Fixes, including security fixes, go into the next release; there
are no backports. Only the latest release is supported, and the app updates itself (or offers
the download, on macOS builds that can't update in place).

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| Anything older | No: update first |

## Deprecation

A setting, file format or behaviour that goes away is announced in the changelog of the release
before the one that removes it. Notes stay plain `.txt`/`.md` files that any editor opens; Lyra
never removes the ability to read notes it wrote before.
